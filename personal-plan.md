# 4-Day Upper/Lower Training Plan

## Overview
- **Split**: 4-Day Upper/Lower — hits every muscle 2x/week (Schoenfeld, Grgic & Krieger, 2018)
- **Duration**: 45–60 min per session
- **Progression**: Last set AMRAP. If 12+ reps, add 2.5 kg next session for that exercise.
- **Rest days**: 3 per week

## Weekly Schedule
| Day | Session |
|-----|---------|
| Monday | Upper A (Strength/Push focus) |
| Tuesday | Lower A |
| Wednesday | REST (walk 30 min, mobility) |
| Thursday | Upper B (Hypertrophy/Pull focus) |
| Friday | Lower B |
| Saturday | REST or 30 min cardio (incline walking, cycling) |
| Sunday | REST |

## Warm-Up (5–7 min, every session)
1. 5 min easy bike/treadmill incline walk
2. World's greatest stretch — 5 each side
3. Band pull-aparts — 2 × 15
4. Arm circles + scapular wall slides — 10 each
5. Bodyweight squats — 10
6. 2 warm-up sets of first exercise at 40% and 60% of working weight

4. **Lat Pulldown** — 3 × 8–10 (last set AMRAP)
5. **Seated Cable Row** — 3 × 8–10 (last set AMRAP)
6. **Dumbbell Lateral Raise** — 3 × 12–15 (last set AMRAP)
7. **Tricep Pushdown (Rope)** — 3 × 12–15 (last set AMRAP)

## Progression Rules
- **Last set AMRAP** (As Many Reps As Possible) with good form — not to failure, leave 1–2 RIR
- If AMRAP set hits **12+ reps**, add **2.5 kg** next session for that exercise
- If 8–11 reps, keep weight the same
- If < 6 reps, drop weight by 2.5 kg next session
- Track all weights and reps in exercise tracker
